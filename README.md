# Emmanouela Tsakalidou - Software Engineering Portfolio

Software engineering portfolio focused on DevOps, CI/CD, backend systems, automation, testing and reliable application delivery.

Built with React, TypeScript and Vite, with automated quality checks and GitHub Actions deployment.

## Featured Engineering Work

### PipelineForge
Local-first DevOps and CI/CD project built around Jenkins Pipeline as Code, distributed Linux build agents, Docker image builds, automated JUnit testing and runtime smoke tests.

Tech:
`Jenkins` · `Docker` · `Java 21` · `Spring Boot` · `Gradle` · `JUnit` · `Linux` · `Bash`

### Jenkins CI Reliability Lab
Hands-on CI infrastructure lab covering distributed Jenkins agents, parallel execution, failure classification, monitoring, retries, credentials and operational troubleshooting.

Tech:
`Jenkins` · `Docker` · `Linux` · `Python` · `pytest` · `Ruff` · `Shell`

### PriceWise
Full-stack grocery price-comparison application with scheduled supermarket data collection, REST APIs, PostgreSQL persistence and real-time updates.

Tech:
`React` · `TypeScript` · `Node.js` · `Express` · `PostgreSQL` · `Prisma` · `Docker`

### C++ Sensor Dashboard
Multithreaded C++17 monitoring application with simulated sensor data, HTTP endpoints and browser-based visualization.

Tech:
`C++17` · `CMake` · `Multithreading` · `HTTP` · `JSON`
